# Claude Code Starter Kit

A learning kit for getting real, working fluency with [Claude Code](https://claude.com/claude-code), not a "click here, everything installs" onboarding flow.

## What this is

Most Claude Code starter kits are written by developers, for developers. They assume you already know what a terminal is, what git does, and what a config file means. This one doesn't assume that.

It's also not a magic installer. Claude Code's own install process is short and worth doing by hand. The goal here isn't to hide it, it's to make sure you understand what each step does before you run it. [`GETTING_STARTED.md`](GETTING_STARTED.md) walks through that, including getting this kit itself onto your machine via git, which is also your first real lesson, not busywork.

## What's in the kit

| File | What it's for |
|---|---|
| [`GETTING_STARTED.md`](GETTING_STARTED.md) | Get the kit, install Claude Code, and run your first session. Read this first |
| [`CLAUDE.md`](CLAUDE.md) | The instructions Claude reads automatically every time you work in this folder, your "house rules" |
| [`GOTCHAS.md`](GOTCHAS.md) | A running log of things that tripped you up and how you got past them. It starts almost empty and you fill it in |
| [`SECURITY.md`](SECURITY.md) | The handful of security rules that actually matter for a beginner (mainly: never paste secrets into a chat) |
| [`REMEMBER.md`](REMEMBER.md) | A place for Claude to remember things about you and your projects between sessions |
| [`PRACTICE_PROJECT/`](PRACTICE_PROJECT/) | A small worked example to practice on before you point Claude Code at something real. Swap it out once you get the hang of it. |

## The idea behind it

Every kit out there solves setup. The hard part is figuring out what to *do* with a working install, and building habits (writing things down, checking Claude's work, knowing when to say "stop, check with me first") that hold up once you're doing something that matters. That's what this kit is actually trying to teach.

## Where this came from

Adapted down from a working engineer's real Claude Code configuration: the same structure, same underlying philosophy, minus the parts specific to their own projects and infrastructure. The full-strength version assumes years of context; this one assumes none.
