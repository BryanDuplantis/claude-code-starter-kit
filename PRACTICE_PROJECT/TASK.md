# Task

Open a Claude Code session in this folder (`cd` into `PRACTICE_PROJECT/`, then run `claude`) and give it this, in your own words:

> Read everything in `notes/`. Build a single `INDEX.md` file that lists each note by date with a one-line summary. Then write one new note of your own in `notes/` — anything, even two sentences — and update the index to include it.

Then:

- **Check its work.** Open `INDEX.md` yourself. Are the summaries actually accurate? Did it miss a file?
- **Correct it if it's wrong.** Tell it directly — "that summary isn't right, here's what the note actually says" — and see how it responds.
- **Ask it to explain a choice.** If it organized the index in a way you wouldn't have, ask why. You're allowed to disagree and have it redo it.

That's it. There's no "correct" output — the point is going through one real round of giving Claude a task, checking the result instead of trusting it, and correcting it when it's off.
