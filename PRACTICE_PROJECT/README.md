# Practice Project

A small, low-stakes task to get you through one real Claude Code session before you point it at something that actually matters. Takes 10-15 minutes.

`notes/` has four short, made-up journal entries. **Start with `TASK.md`, and read it yourself.** Don't have Claude read it for you: it describes a test you'll run on Claude, and letting Claude read it first would spoil the test. ("Read a file yourself" in Step 7 of `GETTING_STARTED.md` shows how to open it.)
