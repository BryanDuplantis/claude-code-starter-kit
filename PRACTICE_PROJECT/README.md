# Practice Project

A small, low-stakes task to get you through one real Claude Code session before you point it at something that actually matters. Takes 10-15 minutes.

## What's here

`notes/` has four short, made-up journal entries. `TASK.md` has your actual instructions.

## When you're done

Once you've got the hang of it, **replace this folder's contents with something real** — actual notes from your actual life or work. The pattern is the same regardless of the domain:

1. Give Claude a handful of real files.
2. Give it a real, concrete task about those files.
3. Watch how it approaches it, check its work, correct it if it's wrong.
4. Notice what you had to explain that you wish you hadn't — that's a candidate for `CLAUDE.md` or `REMEMBER.md` (both one level up, in the main kit folder).

That loop — real material, a real task, checked work, lessons written down — is the actual skill this kit is trying to build. The specific task in `TASK.md` is just a rehearsal.
